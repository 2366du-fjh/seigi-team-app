# 生技課人員分析 APP v3

生產技術課人員、技能與工作內容管理工具。下載本儲存庫後，使用瀏覽器開啟 `index.html` 即可使用，無需安裝依賴。

## 功能

- 五位人員名冊：姓名、職稱、組別、工作內容、生日、入職日。
- 三十項專業技能：一般技術5項、產線設備11項、課長管理6項、副組長專業8項。
- 人員新增、編輯、刪除、組別篩選與搜尋。
- 每週工時及負荷分析。
- 職務說明書編輯、列印與另存PDF。
- CSV匯出、JSON備份及匯入；相容舊版技能評分資料。

## 資料儲存

資料保存在使用中的瀏覽器 localStorage，沒有伺服器或多人同步。更換裝置或清除網站資料前，請匯出 JSON 備份。不同檔案路徑與瀏覽器可能有不同儲存空間。

初始名冊含使用者提供的人員與工作內容；未提供的生日、入職日、工時及技能評分均留白或標示未評估。本儲存庫設為私人。

## 檔案

- `index.html`：主畫面及人員編輯表單。
- `style.css`：響應式畫面及職務說明書列印樣式。
- `app.js`：資料管理、分析、技能矩陣與匯出功能。
- `使用說明.txt`：離線操作說明。
